# Умный портфель

Мобильная браузерная игра-мемори для банковских менеджеров.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите содержимое этой папки в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните настройки и откройте выданную GitHub Pages ссылку на мобильном устройстве.

Игра не использует сервер, регистрацию или внешние библиотеки. Шрифты и иллюстрации находятся внутри папки `assets`.
